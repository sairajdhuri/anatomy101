## Argument and copy deck

Hero claim: explore anatomy through a free interactive atlas. Proof: the Start learning button opens the actual viewer; the page calls out model options and revision tools without promising clinical validation.
System index claim: start with a specific layer. Proof: five real system buttons open those layers.
Footer claim: coverage varies and the artwork is illustrative. Proof: source and coverage links, plus the female warning inside the viewer.

Copy: Anatomy / 101. Explore the human body in 3D. Separate its layers, inspect each structure, and turn your next revision session into active recall. Start learning. Explore systems. Free to explore. Male & female composite models. Notes, bookmarks & quizzes.

## Direction

Dealt: The page is the object, seed 1676636525; palette/type retained. Idea: Anatomy101's supplied anatomical plate becomes the cover of a working digital atlas. Live thing: its system index opens real model layers.

The random folder-stack hero and postcard footer conflict with the explicitly supplied reference and request for fewer sections, so the user's anatomical-plate composition takes precedence: large title at left, a separate text-free illustration at right, and a navy system index. No stock photographs, fake statistics, numbered ornament or decorative rules. One hero illustration is intentional; adding four unrelated photographs would contradict the compact reference.
